# Sutta tables and collection groups task board

Wave goal: ingest the AriyaSavaka curated sutta table from the crawled reddit dataset into the quotes database as a named collection with semantic groups, and ship collection groups as an app feature.

Source of truth: `dumps/ariyasavaka-curated-list.md` (verbatim post body, provenance in `dumps/ariyasavaka-curated-list.json`, commit bb83190). 16 roman-numeral sections in gradual training order, 107 numbered items, 261 sutta markdown links, 44,688 bytes.

Design decisions: suttas are a global registry table; collections gain named ordered groups; quote items and sutta items both carry an optional group id; within a group the ordering is SortShortestFirst on real english translation lengths read offline from the published full graph db (363 MB, 1,300,819 segments, run 20261020T115317Z, built by parse+load from the existing bilara mirror, no sync), unknown lengths keep document order after the known ones; 63 of 471 muids have no per-sutta length: vv51, ja360, ja402 are untranslated in the mirror, the other 60 are an1 muids that exist only inside range segment keys like an1.505-514 in both the root and the en files, so only content-level verse splitting could derive them, out of scope; seed.sql is the only ingest surface (local db verified identical to seed: 109 quotes, 1 collection, 3 categories); sample collection seeding is removed once AriyaSavaka seeds. The muid is the operative handle for our own CLI: T4 adds `qm query suttas` (registry and per-collection listing, ids feed `qm query segments --muid`) and T5 makes `/collections/{cid}/ids.txt` carry the collection's sutta ids alongside quote ids.

First launch attempt (2026-10-20 18:20) landed all three agents in a web-only toolset with no file or shell tools; one agent probed a host escape through a browser MCP before being stopped, both repos verified clean afterwards. The 18:40 relaunch on the general-purpose type hit the same wall: in this harness every non-fork agent type draws a web-only toolset from its definition. Resolution 19:00: all lanes relaunched as forks (they inherit the parent toolset and model), same working tree, file-disjoint lanes, index.lock retries on commit contention.
