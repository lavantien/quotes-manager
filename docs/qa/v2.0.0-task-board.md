## Fan-out protocol

- Communication: agents SendMessage with to: `main` (literal). Replies to any other display name are silently dropped by the harness.
- Status ping every 20 minutes. 30 minutes of silence means the agent is stuck: main disposes it and relaunches from the last recorded progress.
- Async shells: every long or blocking command runs with run_in_background. Never sleep or poll-wait.
- Durable progress: timestamped lines in the task notes file, small atomic commits. Never `git add -A`; stage only owned paths, retry on index.lock contention.
- Conventional Commits, zero AI attribution lines, zero comments in code, max 1000 SLOC per file, CGO_ENABLED=1 with `-tags sqlite_fts5`.
- Slots: 8 development + 1 auxiliary (quota guard throwaways). TaskStop on every completion notification before slot reuse. Orphan sweep at each recycle.
- Guards: quota check every 20 minutes (pause fan-out at 95 percent of the 5 hour window), memcapmon at 16 GB combined working set over repo processes, supervised by a 5 minute cron.
